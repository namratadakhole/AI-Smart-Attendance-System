# AI Face Recognition Attendance System

A Python-based attendance system that uses Computer Vision and AI to automatically recognize faces and mark attendance.

## Features

- Face registration using webcam
- Face encoding with AI
- Real-time face recognition
- Automatic attendance logging
- MongoDB Atlas database integration
- CSV export

## Technologies Used

- Python
- OpenCV
- face_recognition
- NumPy
- MongoDB Atlas (pymongo)
- Git & GitHub
